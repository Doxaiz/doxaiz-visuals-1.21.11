Модуль «Anime» (HUD): одна PNG в правом нижнем углу, слот выбирается в ClickGUI (настройка «Картинка»: 01–06).

Файлы (ровно такие имена):
  anime_01.png … anime_06.png

Путь в ресурсах мода:
  src/client/resources/assets/astrix/textures/gui/anime/

Формат: PNG, любой размер — вписывается в квадрат 300×300 без обрезки (отступы зашиты в коде: снизу 0, справа 94).
Показывается только выбранный слот; остальные файлы можно не класть.

После замены файла: перезапуск или выкл/вкл модуль «Anime».

«Только в ClickGUI» — вкл.: картинка только в ClickGUI; выкл.: и в игре.
