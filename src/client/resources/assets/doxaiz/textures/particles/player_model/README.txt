PlayerModel — текстуры банок (Fanta / MountenDew / Pepsi)
========================================================

Один файл PNG на режим, размер ровно 1500×500 пикселей.

Положи в эту папку (имена файлов см. в модуле PlayerModel):

  src\client\resources\assets\astrix\textures\player_model\
    fanta.png
    mountendew.png
    pepsi.png

Куда класть крышку и дно
------------------------
Отдельные файлы НЕ нужны. Всё в одном PNG по горизонтали три квадрата 500×500:

  px 0–500     — КРЫШКА (вид сверху; рисунок клади в левую треть картинки)
  px 500–1000  — БОК / этикетка (оборачивается вокруг банки)
  px 1000–1500 — ДНО (вид снизу; правая треть)

Высота файла 500 px — у всех трёх зон одинаковая высота (квадрат 500×500 каждая).

Если на стыках между колонками были цветные полосы («рваная» текстура), в коде
добавлен небольшой отступ от границ зон при UV; при рисовании в графике можно
добавить по 2–4 px «безопасного» поля у краёв каждой трети без важных деталей.

Остальные режимы:
  rabbit.png  — кролик (64×64)
  amogus.png  — amogus (64×64, серая UV-карта; цвет тела в настройке Body color)
  freddy.png  — Freddy (100×80)
  tung.png    — Tung (64×64)
