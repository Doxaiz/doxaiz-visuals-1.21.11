Cosmetics (кастомный плащ) — куда положить PNG
==============================

Имя файла (обязательно):
  astrix_cape.png

Путь в проекте (папка репозитория Astrix):
  src\client\resources\assets\astrix\textures\cape\astrix_cape.png

После добавления файла пересобери мод (gradlew build).

Формат: как у плаща в Minecraft / OptiFine — обычно 64×32 px (слева тело плаща, справа можно элитры в той же текстуре по ванильному шаблону). Можно использовать готовый шаблон «cape template» 64×32.

В игре: ClickGUI → Cosmetics → модуль «Cosmetics», включи «Custom cape». Плащ виден на твоём персонаже (в т.ч. если официального плаща у аккаунта нет). У других игроков твой PNG не подменяется.
